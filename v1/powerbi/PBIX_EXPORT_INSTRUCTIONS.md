# ATM Network Expansion Power BI Package

Power BI `.pbix` files are binary files generated by Power BI Desktop. This folder contains a Power BI Project (`.pbip`) with the semantic model, report metadata, theme, measures, and a visual reference preview. Open the project in Power BI Desktop and save it as a `.pbix`.

## Open The Report

1. Install or open Power BI Desktop.
2. Enable preview features if prompted:
   - Power BI Project (`.pbip`) save option.
   - Enhanced report format (`PBIR`), if your Desktop version asks for it.
3. Open:

```powershell
v1\powerbi\ATM_Network_Expansion.pbip
```

4. Refresh the semantic model and enter PostgreSQL credentials for:

```text
Server:   localhost:5432
Database: atm_network_v1
Views:    public.v_atm_locations_powerbi
          public.v_scrape_runs_powerbi
```

5. Save as:

```powershell
v1\powerbi\ATM_Network_Expansion.pbix
```

## Files Included

- `ATM_Network_Expansion.pbip`: Power BI Project entry point.
- `ATM_Network_Expansion.Report`: PBIR report definition with dashboard visuals.
- `ATM_Network_Expansion.SemanticModel`: TMSL semantic model connected to PostgreSQL.
- `dashboard_preview.html`: static visual preview matching the requested dark Scotiabank style.
- `scotia_dark_theme.json`: reusable theme file.

## SQL Server Variant

The project currently targets PostgreSQL. For SQL Server, replace the PostgreSQL partitions in `ATM_Network_Expansion.SemanticModel\model.bim` with the query pattern from `power_query_mssql.m`.
